About CrimeSketch-ID

AI-Powered Facial Sketch and Image Similarity Search System

Academic Case Study & System Objective

CrimeSketch-ID is an academic computer-vision and web application demonstrating similarity ranking between forensic facial sketches, composite drawings, photographs, and live video frames.

In forensic investigation research, witness descriptions often yield hand-drawn or digital composite sketches. Comparing a cross-modal sketch against a database of natural photographs requires mapping both representations into a shared mathematical feature space where geometric and identity distances can be measured.

Core Mathematical Foundations:
  • Face Detection & 5-Point Alignment: OpenCV YuNet predicts bounding boxes and coordinates for both eyes, nose tip, and mouth corners.
  • Feature Space Mapping: A deep convolutional neural network (SFace) transforms aligned 112×112 face patches into 128-dimensional L2-normalized vectors.
  • Similarity Computation: Feature vectors are compared using Cosine Similarity (\( \cos \theta = \frac{\mathbf{u} \cdot \mathbf{v}}{\|\mathbf{u}\| \|\mathbf{v}\|} \)) and Euclidean Distance (\( \|\mathbf{u} - \mathbf{v}\|_2 \)).
Ethical and Legal Notice
Mandatory Academic Disclaimer: {{ system_disclaimer }}

The software does not declare or confirm identity, guilt, or criminal responsibility. Matching candidates are ranked strictly by mathematical feature proximity. Forensic deployment in real-world jurisdictions mandates strict chain-of-custody, human forensic expert review, and legal authorization under applicable laws.

Technology Stack
  • Backend Framework Django & DRF
  • Database MongoDB (PyMongo)
  • Face Detector OpenCV YuNet DNN
  • Feature Extractor SFace (128-D)
  • Machine Learning PyTorch / NumPy
  • Frontend UI Bootstrap 5 & Icons
  • Interactive Video HTML5 / WebRTC
Architecture Note

This project uses a clean, pure MongoDB persistence layer. Django's default SQLite database is completely omitted, eliminating SQL database dependencies while storing candidates, search audit trails, and evaluations in MongoDB.
