System Help & Operational Guide

Step-by-step procedures, technical workflow explanation, and troubleshooting documentation.

How Forensic Sketch Search Works
1. Upload Image / Sketch

Select a composite sketch, pencil portrait, or reference photo (JPG, PNG). The system accepts standard image files.

2. Face Detection & CLAHE Preprocessing

OpenCV YuNet deep neural network detects facial bounding boxes and 5 key facial landmarks. CLAHE contrast adjustment balances pencil strokes.

3. Landmark Alignment & Embedding

The face is aligned using affine transformation (112×112 canvas) and transformed into a 128-dimensional unit feature vector via SFace CNN.

4. Similarity Engine Comparison

The query vector is compared against all candidates stored in MongoDB using Cosine Similarity or Euclidean Distance.

5. Candidate Ranking Display

Results are sorted from highest similarity to lowest, returning the Top-K closest reference candidates.

How Multi-Face Webcam Studio Works
1. Start Camera Feed

Click "Start Camera" to initialize your built-in laptop webcam via browser navigator.mediaDevices.getUserMedia().

2. Multi-Face Capture & Detection

Click "Analyze Multi-Face". The system captures the video canvas and sends it to the backend where YuNet locates all faces in the frame.

3. Individual Face Cropping & Embedding

Each detected person (Face #1, Face #2, etc.) is cropped and converted into its own 128-d embedding vector.

4. Candidate Matching & Labeling

Each face is individually matched against MongoDB candidates. Bounding boxes are drawn with candidate names and similarity percentages.

5. Search Logging

The search event is logged to MongoDB with execution latency telemetry and candidate rankings.

Frequently Asked Questions & Troubleshooting

If a sketch has very faint lines or unusual artistic stylization, the neural network may fail to detect standard eye/nose landmarks. Try using sketches with darker pencil strokes, clearer eye pupils, or adjust the detection threshold to 0.35 in Settings.

When clicking "Start Camera", your browser will display a permission prompt asking for access to your camera. Click "Allow". If blocked, look for the camera icon in your browser URL bar and change permission to "Allow".

The similarity score is a mathematical distance calculation in 128-dimensional embedding space. It reflects relative geometric and feature similarity between the query face and the reference photograph. It is probabilistic and must NEVER be treated as proof of identity or evidence of guilt.
